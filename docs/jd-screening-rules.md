# 岗位原文核验规则（踢掉"特别差"的）

招聘页上的标签（尤其是"经验不限"）不可信，要读岗位原文。命中下列任一条就踢掉，并写明原因，**被踢掉的单独留一页**，规则误伤时可以捞回来。

| 类别 | 判断 |
|---|---|
| 要经验 | 原文出现"2年以上/3年以上…"、"丰富经验"、"资深" |
| 学历/语种 | 要硕士/博士、要日语（N1/N2） |
| 届别 | 27/28届校招、"2026春招"（已过期） |
| 外派外包 | 外派、外包、驻场、派遣、OD、"wai派" 等变体（**标题里也要查**） |
| 套路 | 培训贷、分期、押金、保证金、服装费、"无责底薪"、"底薪+提成"、日结、兼职、代理加盟 |
| 销售伪装 | 电话销售/邀约、拓客、地推、客户开发、业绩提成 |
| 描述过短 | 去掉公司简介后几乎没有内容（阈值别设太高，有些正规岗位描述就很短） |
| 虚报规模 | 招聘页写100人以上，但工商注册资本≤10万（智联职位页自带工商信息） |
| 非技术岗 | 标题含漫剧/短剧/视频/美工/导演/编剧/剪辑/主播/运营/文案/设计师/BD/商务等 |
| 灰产 | 例如非游戏行业公司招"棋牌类游戏开发"，有赌博灰产风险 |

## 不踢但要提示
- 公司成立不足半年；参保人数与规模严重不符；"某某大型公司"这类猎头匿名岗（建议降级或剔除）。

## 查公司真实性（比招聘页可靠）
- 工商信息里看：**成立时间、注册资本、参保人数、经营范围**（经营范围里有没有软件/游戏，能识破"挂羊头"）、司法案件与风险条数。
- 参保人数来自企业年报，可能滞后，但和招聘页相差几十倍本身就值得警惕。
