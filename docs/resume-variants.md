# 简历按方向做多个版本（事实不变，重点不同）

用一份 `data.js` 存全部事实，`scripts/make_variants.js` 生成多个版本：

| 版本 | 调整什么 |
|---|---|
| 通用版 | 原样 |
| 游戏/Unity版 | 求职意向与技能把游戏引擎放最前；游戏项目放第一并展开技术点；其他项目缩短 |
| 前端版 | 前端技能放最前；Web 项目放第一；预留一个前端个人项目的占位 |
| AI/实施版 | AI 技能放最前；**实习/交付经历放到项目之前**（实施岗看重客户沟通与现场经验）；预留 AI 项目占位，**做完才能投，没做完不要发** |

规则：
- 红字【】= 待确认/待补充，生成时标红，投递前必须处理；
- **没做出来的项目只留占位，不写成已完成**；
- 版本之间不凭空增加经历，只调整顺序、详略和措辞；
- 求职者年限短、内容少时 1 页最佳；项目多了可以 2 页，但重点放前半页。
