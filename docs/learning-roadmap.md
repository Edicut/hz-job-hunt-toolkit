# 学习路线（求职者自学用）

> 用法：每个模块都有 **学什么 → 达标标准 → 去哪找 → 怎么让 AI 带着学 → 做出什么**。
> 先做"达标标准"，达标了再往下走。简历里每一行都要能讲 10 分钟：**不要背，要做过**。
> 找课程时用下面给的"搜索关键词"去 B 站 / 慕课 / 官方文档搜，选播放量高、近一年更新的。

## 总路线（4～6 周，边学边投）

| 周 | 做什么 | 产出（可以写进简历） |
|---|---|---|
| 第 1 周 | ① 个人游戏项目整理上 GitHub ② Java Web 课程 Web 项目修漏洞并上 GitHub ③ Git | 两个有 README 的仓库 + 一段 30 秒游戏录屏 |
| 第 2 周 | Python 基础 + 调大模型 API | 命令行聊天脚本、招聘数据分析脚本 |
| 第 3 周 | Agent / RAG 概念 + Dify 实操 | 「某领域知识问答 Agent」做出来，有测试集和准确率 |
| 第 4 周 | 前端 Vue3 把 Agent 接上网页 + 部署 | Vue 对话页 + 公网可访问 |
| 第 5～6 周 | 面试八股 + 模拟面试 + Unity 进阶 | 每个项目一份自己写的讲述稿 |

**不用等学完才投**：第 1 周简历（Unity版/前端版）就可以开始投；第 4 周后再投 AI 版。

---

## 模块 1：Git + GitHub（半天）
- **学什么**：`init / add / commit / push / pull / branch / merge`，写 README，`.gitignore`（Unity 项目别把 Library 文件夹传上去）。
- **达标**：能把一个项目从本地推到 GitHub，别人 clone 下来能看懂。
- **去哪找**：搜「廖雪峰 Git 教程」「Git 十分钟入门」；GitHub 官方的 Hello World 指南。
- **让 AI 带着学**：把下面这段粘给你的 AI：
  > 我是计算机本科应届生，会 C、C#、Java。请用最小例子教我 Git 和 GitHub：先让我自己敲命令，每一步告诉我会发生什么，我敲完贴结果给你检查。重点是把本地项目推到 GitHub 并写好 README。
- **做出**：个人游戏项目仓库、课程 Web 项目仓库。

## 模块 2：把个人游戏项目复盘成"能讲的项目"（Unity 方向的核心，1～2 天）
面试官一定会问，**每一条都用自己的话写答案**：
1. 引擎版本？为什么选它？整体有哪些模块（输入、移动、射击、碰撞、伤害、UI、关卡）？画一张模块图。
2. 角色移动用 `Transform` 还是 `Rigidbody`？区别是什么？
3. 碰撞怎么做？`OnCollisionEnter` 和 `OnTriggerEnter` 的区别？
4. 敌人 AI 怎么写的（状态机 / NavMesh / 直接追踪）？
5. **遇到过的最难的问题是什么、怎么解决的？**（最重要，必须是真实的）
6. 如果现在重做，你会改什么？（例：子弹用对象池；配置用 ScriptableObject）
- **Unity 进阶要补的点**（岗位原文里出现过）：**对象池、状态机、协程、UGUI、资源管理（Addressables / AssetBundle）、热更新的概念、性能优化（Profiler、减少 GC）、设计模式（单例、观察者）**。
- **达标**：每个点能说出"是什么、为什么要用、我项目里哪里用了/可以用"。
- **去哪找**：Unity 官方 Learn（learn.unity.com）、Unity 官方手册；B 站搜「Unity 对象池」「Unity 状态机」「Unity UGUI 教程」「Unity Profiler 性能优化」。
- **让 AI 带着学**：
  > 我做过一个 Unity 3D 个人游戏项目（课程/毕业设计）。请当 Unity 面试官，一次只问我一个问题，问我项目里的实现细节。我回答后你指出不严谨的地方，再追问。从碰撞检测、移动、AI、UI、性能这几个方向问起。
- **做出**：一段 30 秒录屏 + README（玩法截图、技术点、自己负责的部分）。

## 模块 3：Java Web 课程 Web 项目修漏洞（半天～1 天）
如果你的课程项目里**登录是字符串拼接 SQL，会有注入漏洞**；密码是明文；数据库账号写在代码里。**把它改好，就是最好的面试故事**：
- 登录改成 `PreparedStatement`；密码用哈希存（例：BCrypt 或 SHA-256+盐）；数据库配置放配置文件；统一页面编码为 UTF-8。
- **达标**：能讲清楚"SQL 注入是什么、怎么攻击、怎么防"，并演示改前改后的区别（如果学过网络安全课，可以结合靶场实验）。
- **去哪找**：搜「JDBC PreparedStatement 防止 SQL 注入」「Java 密码加密 BCrypt」「JSP MVC 分层」。
- **做出**：一份"漏洞复盘"README，写进简历那条红字里（把"了解并可改"改成"已修复"）。

## 模块 4：Python 基础（3～5 天）
- **学什么**：变量、列表/字典、函数、类、异常、文件读写；`requests`（发请求）、`json`、`pandas`（读表、筛选、统计）、`venv` 虚拟环境。
- **达标**：能写脚本读 Excel/CSV、清洗、统计、保存结果。
- **去哪找**：搜「Python 基础教程 零基础」选 B 站近两年的；廖雪峰 Python 教程；Python 官方教程中文版。你有 C/C# 底子，语法 2～3 天就够，把时间放在"能干活"上。
- **让 AI 带着学**：
  > 我会 C 和 C#，请用对比的方式教我 Python，每讲一个概念给一个 10 行以内的例子，并出一个小练习让我自己写，写完我贴给你批改。
- **做出**：`jobs_analysis.py`：读招聘数据表，统计杭州各岗位薪资区间和高频技能词，画一张图（用你自己抓取的数据，在 `数据\raw\`）。

## 模块 5：大模型 API（2～3 天）
- **学什么**：`messages`（system / user / assistant）、`temperature`、token 与计费、流式输出（stream）、多轮对话怎么保存历史、**Function Calling / 工具调用**。
- **去哪找**：DeepSeek / 通义千问 / 智谱的开放平台官方文档（注册拿 API Key，不要把 Key 写进代码里上传 GitHub）；搜「面向开发者的 LLM 入门教程」「Prompt Engineering for Developers」；Anthropic 官方文档的 tool use 一章也值得读。
- **达标**：能用 Python 发一次对话请求；能写一个带历史的命令行聊天程序；能让模型调用一个自己写的函数（比如查天气/查本地文件）。
- **做出**：`chat.py` 命令行聊天。

## 模块 6：RAG 与 Agent 概念 + Dify（1 周，最核心）
必须能**用自己的话**讲清楚这些（面试 AI 岗必问）：

| 概念 | 要能回答的问题 |
|---|---|
| Prompt / System Prompt | 怎么限定角色和回答范围、怎么要求"不知道就说不知道" |
| Embedding / 向量库 | 为什么文字能变成向量、"相似"是什么意思 |
| 切片（chunk） | 切多大合适？切太大/太小各有什么问题 |
| RAG 流程 | 切片→向量化→检索→拼进 prompt→生成；为什么能减少胡编 |
| Rerank | 为什么要粗检再精排 |
| 幻觉 | 怎么缓解（限定范围、给出处、拒答） |
| Agent | 和普通对话的区别：模型自己决定调什么工具、看结果再决定下一步 |
| 工具调用 / MCP | MCP 解决什么问题 |
| 评测 | 你怎么知道好不好？测试集、准确率 |

- **去哪找**：Dify 官方文档（docs.dify.ai）；搜「Dify 知识库 RAG 教程」「Dify Agent 工具调用」「Dify Docker 部署」；GitHub 搜 Datawhale 的 LLM / Agent 入门教程（他们是国内的 AI 开源社区，教程免费）；搜「RAG 原理 通俗讲解」「MCP 是什么」。
- **让 AI 带着学**：
  > 我要做一个某领域知识问答 Agent。请先用大白话给我讲 RAG 的完整流程，每一步讲完让我用一句话复述，你来纠正。再带我设计 20 个测试问题，和怎么判断答对了。
- **项目验收标准（做到才算"做出来"）**：
  1. 知识库至少 5 类某领域资料（你熟悉领域的 5 类资料——你在此前的工作讲过，资料你比别人熟）；
  2. system prompt 限定"只根据知识库回答，答不出就说不知道，并给出处"；
  3. **20 题测试集**，记录答对几个；调整切片大小和检索参数后再测一遍，**写下前后的准确率**（面试时这就是"我怎么优化的"）；
  4. 能通过 API 被网页调用。
- **简历写法（做完才能写，数字必须是真实测出来的）**：
  > 某领域知识问答 Agent｜Dify + 大模型 API + Vue3：整理 5 类某领域技艺资料构建知识库；设计 system prompt 限定回答范围并输出出处；建立 20 题测试集，通过调整切片与检索参数，准确率由 X% 提升到 Y%；前端用 Vue3 实现对话界面。

## 模块 7：前端 Vue3（1 周，可与模块 6 交叉）
- **学什么**：`ref/reactive`、`computed`、`watch`、生命周期、组件通信（props/emit）、Pinia、Vue Router、`fetch/axios` 调接口（loading 与报错处理）、Vite 打包。
- **去哪找**：Vue 官方中文文档的教程（cn.vuejs.org）从头做一遍；搜「Vue3 入门 2025」。
- **前端八股要能答**：`var/let/const`、闭包、原型链、`this`、事件循环（宏任务/微任务）、Promise/async-await、深浅拷贝；盒模型、flex、BFC、居中；跨域与 CORS、cookie/localStorage；Vue 响应式原理（Proxy）、`v-if` vs `v-show`、`key` 的作用。
- **做出**：聊天界面，对接模块 6 的 Agent。

## 模块 8：实施岗要补的（3～5 天，投实施岗再学）
- Linux 常用命令（`ls cd cp mv rm cat tail -f grep ps top kill`、看日志、查端口 `ss/netstat`）；
- Docker：镜像和容器的区别、`docker run / ps / logs / exec`、`docker compose up -d`；
- SQL（MySQL）：增删改查、`JOIN`、`GROUP BY`、索引是什么；
- 网络：IP/端口/DNS、HTTP 状态码（200/301/404/500/502）、Nginx 反向代理；
- **排障思路**：服务起不来 → 看日志 → 查端口 → 查配置 → 查网络。
- **做出**：把 Dify 部署到一台云服务器，公网可访问；**踩过的坑都记下来**，面试讲实施经验时就讲这个。

## 每个方向的面试重点（对应不同简历版本）

- **Unity 游戏版**：个人游戏项目细节 + 对象池/状态机/协程/UGUI/性能优化；手写题可能考 C# 基础（值/引用类型、装箱拆箱、委托与事件、GC）。
- **前端版**：JS/CSS/Vue 八股 + 课程 Web 项目/个人游戏项目做了什么。
- **AI/实施版**：RAG 流程、Agent、你的测试集和准确率、部署过程中的坑；客户沟通场景题（"客户说系统打不开你怎么排查"）。

## 必须准备的 6 个通用问题（自己写答案，别背）
1. 自我介绍（1 分钟）：学 VR→专升本学计算机→做过个人游戏项目/课程 Web 项目/Agent→想做什么。
2. 为什么之前做的是某领域活动、现在转技术？（实话：本专业是计算机，活动经历锻炼了沟通和现场应变，对实施/对接需求有用）
3. 最难的一个技术问题和你怎么解决的。
4. 你的缺点？（真实且正在改：工程经验少，所以这几周用项目补）
5. 为什么选我们公司？（投前用"公司调研表"看过官网和产品，说出具体点）
6. 期望薪资？（先查好该岗位在杭州的市场区间，数据表里有）

## 模拟面试（每天一轮，用你电脑上的 AI）
> 你是杭州一家公司的【Unity / 前端 / AI 应用】技术面试官。根据我的简历问我 10 个问题，一次只问一个，我回答后给我打分（满分 10）并追问。先从我简历里的项目问起。

## 红线
- 不要写"在读"，不要写没做过的项目和数字。面试官会追问细节，一追就穿。
- 红字没补完、项目没做完，对应的简历版本先不要投。
